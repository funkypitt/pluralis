Pluralis

E-ink friendly RSS / Atom feed reader for Android.

Overview

Pluralis is a lightweight, local-first RSS / Atom reader with a paginated reading mode designed for e-ink displays. Subscribe to any RSS or Atom feed; articles are sorted chronologically with source spreading. No accounts, no tracking, no server — every byte stays on the device. Flutter, min Android SDK 21.

Features

  • E-ink reading mode — paginated article reader, adaptive font sizing, serif typography (Merriweather), tap zones for page turns, high-contrast layout
  • RSS / Atom aggregator — chronological with source spreading
  • Bookmarks — save articles for later, auto-cleaned after 90 days
  • OPML import / export — bring in your existing subscriptions, share them out
  • Substack support — paid Substack content via cookie authentication, CSV import / export
  • Fully local — no accounts, no tracking, no server
